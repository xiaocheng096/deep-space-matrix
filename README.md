# 深空矩阵 · Deep Space Matrix

一款单文件、零依赖的卡片式自动化工厂游戏。在深空中规划矿脉、铺设传送轨道路线、把矿石一步步炼成金属锭，全部用鼠标拖拽完成。

打开 https://bito.li/Deep-space-matrix 即可游玩，不需要安装、不需要联网、不加载任何第三方库。

---

## 玩法

1. **新游戏** — 输入一个种子（数字或任意文字），或点「随机」，生成属于你的矿脉地图。
2. **点科技** — 用初始物资解锁工具、采集、冶炼、自动化等科技，解锁后才能建造对应设备。
3. **建设备** — 从底部建造栏拖设备到画布：采矿机、熔炉、制造台、风力涡轮机。
4. **连线路** — 从设备的**输出接口**按住拖到另一端设备的**输入接口**，选择要铺的「道」。
5. **供货核心** — 把成品送进地图中央的**工厂核心**，核心会持续累计接收量。

沙盒模式下所有科技默认解锁，资源不设限，专心搭产线。

## 三种「道」

不同货物走不同的道，颜色一眼可辨：

| 道 | 颜色 | 造价 | 传送对象 |
|---|---|---|---|
| 传输轨道 | 青 | 铁 2 · 石 2 | 固体货物（矿石、金属锭） |
| 管道 | 橙 | 铁 2 · 铜 2 | 液体（熔液） |
| 电线路缆 | 金 | 铜 3 · 银 1 | 电力，为设备供电 |

接错的组合会被拦下并给出提示，例如把熔液塞进轨道、或给风力涡轮机接输入。

## 接口

- **工厂核心**：12 个输入接口，四面各 3 个，只进不出。
- **其他设备**：4 个接口，左 2 输入、右 2 输出（风力涡轮机 4 个全是输出）。
- 一个接口只能接一条线，接满即插不进；点击已连接的输入接口可断开该线。
- 设备没通电时运行速度降为 40%——记得先拉电缆。

## 地图与种子

世界由种子确定性生成：数字种子直接使用，文字种子经哈希后进入 PRNG。同一颗种子永远生成同一张图，分享种子号即可分享地图。

共 70 块矿脉，分内 / 中 / 外三圈环带撒点，储量 600–1900。右下角的半透明种子徽标可点击复制。

## 存档

进度保存在浏览器 localStorage，主菜单「继续游戏」中可读取、保存或删除。清空浏览器数据会一并清空存档。

## 技术说明

- 单个 HTML 文件，HTML + CSS + 原生 JavaScript（IIFE，`'use strict'`），无构建步骤。
- 渲染：`transform: translate3d + scale` 的相机层 + SVG 连线层。
- 世界生成：`xmur3` 哈希 + `mulberry32` 伪随机。
- 生产：采矿机 → 熔炉（矿石 → 熔液）→ 制造台（熔液 → 金属锭）→ 工厂核心。
- 电力：电缆连通性 BFS 判定，未通电设备降速。
